### [Critical Linux NFS Server Vulnerability Allows Root Access Without Authentication](https://opensec.in/blog/nfs2root-cve-2026-99362) ⭐️ 8.0/10

OpenSec has disclosed CVE-2026-99362, a critical 9.8 CVSS-scored pre-authentication heap overflow in the Linux kernel&\#x27;s nfsd component. The vulnerability, present since Linux 3.16 \(2014\), allows attackers to gain root privileges without authentication by sending a single connection to tcp/2049. Fixed versions include 6.12.117, 6.18.61, 7.3.2, and 7.4-rc1, requiring kernel upgrades and restarts for mitigation.

telegram · zaihuapd · Nov 27, 12:57

**「Background」** The Network File System \(NFS\) is a distributed file system protocol that allows users to access files over a network as if they were on their local machines. This critical vulnerability in the Linux kernel&\#x27;s NFS server implementation represents a severe security flaw that has existed since 2014, affecting all supported Linux versions that include NFSv4.1 or 4.2 capabilities. The pre-authentication nature of the vulnerability means systems are exposed to compromise even before proper authentication mechanisms can be applied.

**「Impact」** Organizations running file servers, NAS devices, or cluster storage nodes with NFSv4.1 or 4.2 enabled face immediate risk of complete system compromise, as attackers can gain root access without any authentication or prior access to the system.

### [Minecraft Bedrock Edition Resource Pack Vulnerability](https://www.zaikei.co.jp/article/20261119/878386.html) ⭐️ 7.0/10

The vulnerability enables attackers to delete save files, obtain player IP addresses, and on Windows systems, silently execute batch files to download malware when joining servers with resource pack auto-download enabled. Mojang has addressed the issue in version 26.65, while AxmBro has released a Windows detection tool that can identify content.zipe files but cannot determine if a resource pack is malicious.

telegram · zaihuapd · Nov 27, 18:04

**「Resource Packs in Minecraft」** Resource packs in Minecraft Bedrock Edition are customizable content packages that modify game assets like textures, models, and UI elements. These packs, typically distributed as .mcpack files or folders, are designed to enhance or change the game&\#x27;s visual appearance without affecting core gameplay mechanics. The vulnerability exploited how these packs interact with the game&\#x27;s Ore UI framework, allowing malicious code execution when players joined servers with automatic resource pack downloads enabled.

**「User Impact」** Players who haven&\#x27;t updated to version 26.65 or later remain vulnerable to data theft and malware infection when connecting to multiplayer servers with resource packs enabled, potentially resulting in loss of game progress and compromised personal information.
